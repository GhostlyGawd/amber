Amber

One memory across every agent.

Memory that doesn't rot.

Local-first, long-term memory for AI coding agents. One Go binary, one SQLite file you own. No Docker, no key, no account. Offline by default.

Instructions are what you tell an agent (CLAUDE.md).
Memory is what it learns (Amber). 
# two minutes to your first memory
amber init
amber remember "We deploy billing to Fly.io on Fridays" --type decision
amber recall "where does billing deploy"

# ten minutes to a populated store — from history you already own
amber digest --transcripts 30d
amber review

What makes it different

  • Treats memory as an attack surface. Trust tiers, quarantine for untrusted input, a poisoning suite in CI. Content from a web page never auto-injects until you review it.
  • Retroactive onboarding. A reviewed store built from your own transcript history in about ten minutes.
  • Recall you can audit. recall --why shows which memories were injected, their scores, and why.
  • Never auto-deletes. Consolidation merges and demotes — every action journaled and reversible. Aged memories leave injection, never the store.
  • Yours to read. Plain SQLite. Open it with any tool. No telemetry, no nags.
